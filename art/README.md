# Персонажи и локации «Между строк»

Каталог для просмотра: `dist/art.html`. Запуск из корня репозитория:

```sh
python3 -m http.server 4173 --bind 0.0.0.0 --directory dist
```

Откройте путь `/art.html` на сервере проекта. Каталог позволяет выбрать историю, персонажа, костюм, эмоцию и фон. Основной экран чтения подключает эти портреты к размеченным репликам через `dialogue-data.js` и `reader.js`. Каталог остаётся отдельной страницей для просмотра ресурсов.

## Область работы

Три опубликованные первые серии, по 13 сцен. Все 14 основных и второстепенных персонажей с репликами, звонками, письмами/записями или значимым появлением в диалоге:

- **Пока город спит:** Лера, Марк, Нина, отец Леры и Нины.
- **Не случайные:** героиня, Саша, синьора Бьянки, подруга, Кирилл Ветров, продюсер.
- **Тёмная сторона Луны:** Лера, Рен, капитан Воронова, диспетчер Земли.

Две Леры имеют независимые идентификаторы и разные образы. Имена безымянным героям не придуманы. Возраст и внешность, не заданные текстом или обложками, являются художественными решениями. Образы Марка, Саши, летней героини и Рена опираются на существующие обложки. Упоминаемые родственники, смотритель, Катя, безымянные прохожие и кассирша без реплик не получили отдельные диалоговые портреты. Неопубликованные продолжения в этот набор не входят.

## Формат изображений

PNG с настоящим альфа-каналом, листы 3 × 3. В одном листе один человек и один костюм, девять выражений. Порядок слева направо, сверху вниз:

| Ячейка (с нуля) | ID | Выражение |
|---|---|---|
| 0 | neutral | Спокойствие, внимание |
| 1 | smile | Радость, улыбка; у Саши и летней героини смех |
| 2 | tender | Нежность, сочувствие, уязвимость |
| 3 | suspicious | Недоверие, настороженность |
| 4 | angry | Гнев, сдержанное раздражение |
| 5 | surprised | Удивление, неверие |
| 6 | afraid | Страх, тревога, срочность |
| 7 | sad | Грусть, боль, вина, усталость |
| 8 | determined | Решимость, твёрдость |

Это девять групп выражений для текущего текста, а не утверждение, что девять изображений покрывают любые возможные человеческие эмоции или будущие серии. В каталоге можно проверить нюансы каждого рисунка. Для более тонкой анимации речи потребуются дополнительные кадры рта и глаз.

Летняя героиня: повседневная блузка и светлое вечернее платье с распущенными волосами. Космическая Лера: комбинезон и скафандр с прозрачным забралом. Двойники используют узнаваемое лицо оригинала: отдельный персонаж не должен случайно менять внешность.

Листы служат атласами: отдельные PNG для каждого выражения не нарезаны. `art.js` показывает одну ячейку средствами CSS, сохраняя исходное качество и прозрачность. Пример:

```css
.portrait {
  aspect-ratio: 1;
  background-image: url(assets/characters/city-mark.png);
  background-size: 300% 300%;
  background-position: 50% 0%; /* улыбка, ячейка 1 */
}
```

Формула позиции: `x = (cell % 3) * 50%`, `y = floor(cell / 3) * 50%`. Нельзя использовать `object-fit: cover` для полного листа как для одиночного лица.

## Данные и последующее подключение

`dist/assets/art-manifest.json` содержит персонажей, костюмы, порядок эмоций, локации и карту всех 39 сцен. Индексы историй, сцен и ячеек начинаются с нуля. `scenes[].characters` — перечень относящихся к сцене героев, а не список физически присутствующих и не автоматическая атрибуция каждой строки. `scenes[].emotions` — набор подходящих выражений для режиссуры сцены.

При подключении к репликам нужно задавать `speakerId`, `emotionId`, `costumeId` и способ появления (`in-person`, `phone`, `recording`, `video`, `memory`, `message`). Авторский текст не следует ошибочно подписывать героине как произнесённую реплику. Пример:

```json
{
  "speakerId": "city-nina",
  "emotionId": "afraid",
  "costumeId": "cardigan",
  "delivery": "phone",
  "text": "Не смотри туда"
}
```

Отец в городе присутствует только на фотографии/записи; Нина в сценах 8, 12 и 13 — запись, телефон и фигура в окне. Летняя подруга в сцене 6 — письмо, в 12 — видеосвязь. Кирилл в сцене 8 изображён на афише. Диспетчер в космической сцене 12 — радиоголос. Для этих случаев полезна подпись источника голоса. Не показывать одновременно два одинаковых портрета Нины без пояснения «голос» / «окно».

Для записей из будущего добавлены отдельные листы: Лера с небольшой травмой губы и постаревший, измотанный Рен. Они указаны в `scenes[].inserts` отдельно от находящихся рядом героев. Скафандр подходит и для двойника Леры в финале. Детское архивное фото Леры не входит в диалоговые портреты.

## Фоны

Фоны организованы по историям в листы 3 × 3, без наложенных героев и интерфейса. Каждая сцена ссылается на свою ячейку. Повторяющиеся места используются повторно. У моста есть версии с погашенным и горящим окном маяка; у станции — обычная внешняя обшивка и финальный вид с освещёнными окнами и вторым тросом. Это компактные фоновые изображения внутри атласов; для полноэкранного показа на больших мониторах предпочтительна отдельная генерация выбранного кадра в большем разрешении.

Слова основных текстов и варианты выбора сохранены. В сохранение добавлена позиция `beat` внутри сцены; старые сохранения открываются с первой реплики сохранённой сцены. Service Worker обновлён для нового экрана чтения. Галерея не включена в предварительный офлайн-кеш игры, чтобы не загружать все художественные материалы каждому читателю.
