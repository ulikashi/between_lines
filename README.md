# Между строк

Авторская браузерная интерактивная новелла: три короткие истории, выборы, три типа финала, избранное, поиск, фильтры и сохранение в localStorage. Без сборки и зависимостей.

Запуск: `python3 -m http.server 4173 --directory dist`

Статические файлы находятся в `dist/`. Оформление — бордовый бархат, антиква Cormorant Garamond, пергамент и состаренное золото. Изображения созданы встроенным Imagegen и сохранены в `dist/assets/`. Шрифты загружаются из Google Fonts. Игровой прогресс хранится только в текущем браузере.

## Изображения и брифы

Генерация: встроенный Imagegen, не CLI. Все изображения без надписей и логотипов.

- `dist/assets/salon.png`: широкий кинематографический фон старого европейского театра-отеля. Бордовые бархатные портьеры, позолоченные люстры, свечи; справа золотой поднос с жемчугом, хрустальными бокалами, сургучным приглашением и белой оперной перчаткой. Слева свободное тёмное пространство для текста. Плёночная фактура, глубокая светотень, бордовый, золото, слоновая кость.

## Проверки

`node --check dist/app.js`. В браузере проверены прохождение первой истории до финала и изменение показателей; просмотр нового оформления библиотеки и экрана чтения на ширине 390px.

## Первые серии и мобильное чтение

Первые серии находятся в `dist/episodes.js`. Движок использует фактическое число сцен. Продолжения и сценарные планы хранятся локально в `private/` (исключено из Git и не входит в `dist/`).

На телефоне чтение полноэкранное; меню закреплено сверху, позиция прокрутки и выборы сохраняются. На планшете обложка находится над текстом, на компьютере — слева. Каталог перестраивается в одну, две или три колонки. Service Worker сохраняет файлы сайта для повторного открытия без сети после полной первоначальной загрузки; внешние шрифты при недоступности сети заменяются системными.

У новых расширенных серий отдельный ключ сохранения `between-lines-episodes-v2`, поскольку сцены прежних коротких историй не соответствуют новым. Старое сохранение не удаляется.

## Интерактивное чтение

Экран чтения показывает фон сцены и одну реплику за раз. Персонаж появляется только у размеченной прямой речи, письма или записи; у авторского текста портрет скрыт. Эмоции и говорящие указаны вручную в `dist/dialogue-data.js`, исходные слова сохранены в `dist/episodes.js`. Кнопки «Далее» / «Назад» и стрелки клавиатуры перемещают внутри сцены. Выбор появляется в конце сцены. Возврат не отменяет уже сделанные выборы; для другого прохождения используется «Сначала».

Сохранение `between-lines-episodes-v2` сохраняет также номер реплики `beat`; прежние сохранения совместимы. `dist/visual-assets.js` — статическая копия каталога `dist/assets/art-manifest.json` для чтения без дополнительного запроса. При изменении каталога обновляйте и эту копию. Посмотреть образы отдельно можно на странице `/art.html`.

Офлайн доступны оболочка и тексты после первой загрузки, а портреты и фоны — после их просмотра онлайн. При недоступном рисунке остаются текст, имя и базовая обложка. Фоны в текущих атласах имеют небольшое разрешение; на больших экранах они мягче портретов.

Проверка чтения (при запущенном сервере): `READER_URL=http://127.0.0.1:4175/ python3 tests/reader_smoke.py`. Требуется Python Playwright и Chromium. Проверяются все 39 сцен, порядок исходных слов, 351 кадр, выборы, очки, старые сохранения, возобновление чтения и офлайн-текст.

Перед новой историей можно выбрать имя героини или пропустить: значения по умолчанию — Лера (Северск), Вера (Италия), Лера («Луна-9»). Имена хранятся отдельно для каждой истории в `state.names`, сохраняются при начале заново и подставляются в реплики и подпись героини. Начатые старые сохранения получают исходное имя автоматически. Итальянская история современная: героиня, Саша и Кирилл — русскоязычные приезжие, синьора Бьянки — местная хозяйка. Проверка: `READER_URL=http://127.0.0.1:4176/ python3 tests/names_smoke.py`.
